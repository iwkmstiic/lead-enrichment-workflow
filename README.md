# Lead Enrichment Workflow

## Overview

An AI-powered lead enrichment workflow built with n8n that analyzes incoming sales leads, generates business insights, assigns lead scores, and prepares personalized outreach recommendations.

The workflow helps sales teams qualify leads faster and prioritize high-value opportunities automatically.

---

## Features

- AI-powered lead analysis
- Company summary generation
- Lead scoring
- Qualification assessment
- Personalized outreach suggestions
- Google Sheets integration
- Gmail notifications
- Structured JSON output

---

## Tech Stack

- n8n
- Gemini AI
- Google Sheets
- Gmail
- JSON
- Workflow Automation
